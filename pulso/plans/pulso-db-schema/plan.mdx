## Objective

Introduce a local-first data layer to PULSO using **Drizzle ORM** on top of **expo-sqlite**. The schema covers two concerns:

1. **Auth** — users, sessions, and device registration. Designed so every future AI recommendation can be traced to a user, device, and context snapshot.
2. **App data** — all entities the five current screens read and write: workout sessions, nutrition logs, body measurements, streaks, achievements, and coach messages.

**Done when:** Drizzle types compile, `useLiveQuery` returns real rows from SQLite, and the five screens no longer depend on the in-memory `AppContext`. The AI tables ship empty and are populated by a future `generateRecommendation()` call.

**Non-goals for this iteration:** server sync, coach-side write paths, push notification plumbing, and the AI generation call itself.
</rich-text>

<callout tone="decision">
**SQLite over a remote DB.** PULSO is a local-first athlete app — all workout logging, meal marking, and weigh-ins must work offline. The device is the source of truth. Drizzle on expo-sqlite gives typed queries with zero network dependency. A future sync layer can stream deltas to a backend without changing the schema shape.
</callout>

<rich-text>
## Auth schema

The auth layer is minimal for a mobile-only local database. Passwords are stored as **SHA-256 hashes** via `expo-crypto` (ships in Expo Go — no custom build). A future server-side upgrade can swap to Argon2/bcrypt on the API side while keeping the same `users` table shape.

Sessions carry a `tokenHash` (SHA-256 of the raw bearer). The raw token is kept in `expo-secure-store` only — it never touches SQLite. A token stolen from the database file is useless without the raw value.

The `devices` table stores the `expo-application` installation ID and the Expo push token. This is the foundation for per-device AI personalization ("this device trains at 7 am") without requiring a server.

The `role` column (`athlete | coach | admin`) is present from day one so the coach bundle can be added later without a schema migration.
</rich-text>

// src/db/schema/auth.ts
import { integer, sqliteTable, text, uniqueIndex } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
  id:           text('id').primaryKey(),                       // nanoid() — 21-char URL-safe
  email:        text('email').notNull().unique(),
  passwordHash: text('password_hash').notNull(),               // SHA-256 hex via expo-crypto
  role:         text('role', { enum: ['athlete','coach','admin'] })
                  .notNull().default('athlete'),
  verified:     integer('verified', { mode: 'boolean' }).notNull().default(false),
  createdAt:    integer('created_at', { mode: 'timestamp_ms' }).notNull(),
  updatedAt:    integer('updated_at', { mode: 'timestamp_ms' }).notNull(),
});

export const sessions = sqliteTable('sessions', {
  id:        text('id').primaryKey(),
  userId:    text('user_id').notNull()
               .references(() => users.id, { onDelete: 'cascade' }),
  deviceId:  text('device_id'),                               // FK to devices, nullable on first login
  tokenHash: text('token_hash').notNull().unique(),           // SHA-256 of raw bearer; raw stays in SecureStore
  expiresAt: integer('expires_at', { mode: 'timestamp_ms' }).notNull(),
  createdAt: integer('created_at', { mode: 'timestamp_ms' }).notNull(),
});

export const devices = sqliteTable('devices', {
  id:          text('id').primaryKey(),
  userId:      text('user_id').notNull()
                 .references(() => users.id, { onDelete: 'cascade' }),
  fingerprint: text('fingerprint').notNull(),                 // expo-application installationId
  platform:    text('platform', { enum: ['ios','android','web'] }).notNull(),
  osVersion:   text('os_version'),
  appVersion:  text('app_version'),
  pushToken:   text('push_token'),                           // Expo push token — AI nudge delivery
  lastSeenAt:  integer('last_seen_at', { mode: 'timestamp_ms' }).notNull(),
  createdAt:   integer('created_at',  { mode: 'timestamp_ms' }).notNull(),
}, t => ({
  uniqueFingerprint: uniqueIndex('devices_fingerprint_user')
    .on(t.fingerprint, t.userId),
}));

## Auth utilities — src/lib/auth.ts

Raw token → `SecureStore`. Hash → `sessions` table. `getActiveSession()` is called on every app resume to gate the tab navigator.
</rich-text>

```typescript
// src/lib/auth.ts
import * as Crypto from 'expo-crypto';
import * as SecureStore from 'expo-secure-store';
import { eq } from 'drizzle-orm';
import { nanoid } from './id';
import { db } from '@/db';
import { sessions, users } from '@/db/schema';

const TOKEN_KEY = 'pulso_session_token';

async function sha256(input: string) {
  return Crypto.digestStringAsync(
    Crypto.CryptoDigestAlgorithm.SHA256, input,
  );
}

export async function signUp(email: string, password: string) {
  const id = nanoid();
  await db.insert(users).values({
    id, email,
    passwordHash: await sha256(password),
    role: 'athlete', verified: false,
    createdAt: new Date(), updatedAt: new Date(),
  });
  return id;
}

export async function signIn(email: string, password: string) {
  const [user] = await db.select().from(users)
    .where(eq(users.email, email)).limit(1);
  if (!user || user.passwordHash !== await sha256(password))
    throw new Error('invalid_credentials');

  const rawToken  = nanoid(48);
  const expiresAt = new Date(Date.now() + 30 * 24 * 60 * 60 * 1000); // 30 days

  await db.insert(sessions).values({
    id: nanoid(), userId: user.id,
    tokenHash: await sha256(rawToken),
    expiresAt, createdAt: new Date(),
  });
  await SecureStore.setItemAsync(TOKEN_KEY, rawToken);
  return user;
}

export async function getActiveSession() {
  const raw = await SecureStore.getItemAsync(TOKEN_KEY);
  if (!raw) return null;
  const [session] = await db.select().from(sessions)
    .where(eq(sessions.tokenHash, await sha256(raw))).limit(1);
  if (!session || session.expiresAt < new Date()) return null;
  return session;
}

export async function signOut() {
  const raw = await SecureStore.getItemAsync(TOKEN_KEY);
  if (raw) await db.delete(sessions)
    .where(eq(sessions.tokenHash, await sha256(raw)));
  await SecureStore.deleteItemAsync(TOKEN_KEY);
}
```

## Nano-id helper — src/lib/id.ts

No external package — 21-char URL-safe alphabet, same as the nanoid npm package.
</rich-text>

```typescript
// src/lib/id.ts
const ALPHABET = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789_-';

export function nanoid(size = 21): string {
  let id = '';
  const bytes = new Uint8Array(size);
  crypto.getRandomValues(bytes);
  for (let i = 0; i < size; i++) {
    id += ALPHABET[bytes[i] & 63];
  }
  return id;
}
```

<callout tone="warning">
**expo-secure-store requires a custom build.** `SecureStore.setItemAsync` is not available in Expo Go. For local development, swap it temporarily for `AsyncStorage` and add a TODO comment. Everything else — expo-sqlite, expo-crypto, drizzle — runs in Expo Go without a build.
</callout>
